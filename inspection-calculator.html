How Inspection Calculator Works

Deviation = Measured Size − Nominal Size

If the measured size is between the Upper Limit and Lower Limit, the result is PASS.

If the measured size is outside the specified limits, the result is FAIL.

Example: Nominal = 50.000 mm, Upper Limit = 50.020 mm, Lower Limit = 49.990 mm and Measured = 50.010 mm → PASS.
