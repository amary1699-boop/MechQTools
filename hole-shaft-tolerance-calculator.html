How This Calculator Works

  • Maximum Size = Nominal Size + Upper Deviation
  • Minimum Size = Nominal Size + Lower Deviation
  • Total Tolerance = Maximum Size − Minimum Size
  • Deviation from Nominal = Actual Size − Nominal Size
  • Actual size is PASS when it lies between the minimum and maximum limits.
Example:

Nominal Size = 50 mm
Upper Deviation = +0.020 mm
Lower Deviation = −0.010 mm
Actual Size = 50.005 mm

Maximum Size = 50.020 mm
Minimum Size = 49.990 mm
Total Tolerance = 0.030 mm
Actual Size 50.005 mm → PASS
