Formulas:

Upper Limit = Basic Size + Upper Deviation
Lower Limit = Basic Size + Lower Deviation
Total Tolerance = Upper Limit − Lower Limit

How to use

  1. Enter the Basic Size.
  2. Enter the Upper Deviation.
  3. Enter the Lower Deviation.
  4. Click Calculate Tolerance.

Example

Basic Size = 50 mm
Upper Deviation = +0.020 mm
Lower Deviation = -0.010 mm

Upper Limit = 50.020 mm
Lower Limit = 49.990 mm
Total Tolerance = 0.030 mm

Important:
Enter deviations in millimetres. For example, enter 0.020 for +0.020 mm and -0.010 for -0.010 mm.
