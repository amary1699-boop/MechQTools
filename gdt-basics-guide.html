GD&T Basics Guide

Understand Geometric Dimensioning and Tolerancing with practical engineering and inspection examples.

Home  ›  Guides  ›  GD&T Basics

What is GD&T?

GD&T stands for Geometric Dimensioning and Tolerancing. It is a standardized engineering language used to define acceptable variation in the geometry of a component.

It controls features such as size, form, orientation, location and relationship between different surfaces or axes.

Hindi: GD&T drawing par part ki shape, position, direction aur geometric variation ko clearly define karne ka standard method hai.

Why Use GD&T?

  • Clear engineering drawing interpretation
  • Better manufacturing communication
  • Controlled assembly and fit
  • Consistent inspection method
  • Reduced rejection and manufacturing confusion
Hindi: GD&T se manufacturing aur inspection team ko pata chalta hai ki feature kitni variation ke saath acceptable hai.

1. Datum A, B, C

What is a Datum?

A datum is a theoretically exact reference used for measurement and geometric control. A datum feature is the actual surface, hole or feature used to establish that reference.

Illustration only — actual datum selection depends on drawing design.

  • Datum A: Primary reference
  • Datum B: Secondary reference
  • Datum C: Tertiary reference
Hindi: Datum measurement ke liye reference hota hai. A, B, C ka order drawing ke according primary, secondary aur tertiary reference ko represent karta hai.
Important: Datum A, B, C ko apni taraf se assume nahi karna chahiye. Drawing par specified datum features ko follow karein.

2. Feature Control Frame (FCF)

Feature Control Frame tells the geometric tolerance, tolerance value, and applicable datum references.

⌖ ⌀ 0.10 A B C

Example interpretation:

  • ⌖ = Position tolerance symbol
  • ⌀ 0.10 = Cylindrical tolerance zone diameter 0.10 mm
  • A, B, C = Datum references
Hindi: Feature Control Frame mein geometric symbol, tolerance value aur datum references diye hote hain. Isko complete drawing context ke saath read karna chahiye.

3. Important GD&T Controls

Form

Flatness

Surface ko do parallel planes ke beech control karta hai.

Hindi: Surface kitni flat hai.

Form

Straightness

Line element ya axis ki straightness control karta hai.

Hindi: Line ya axis kitni seedhi hai.

Form

Circularity

Each circular cross-section ki roundness control karta hai.

Hindi: Circle kitna round hai.

Form

Cylindricity

Complete cylindrical surface form control karta hai.

Hindi: Cylinder ki overall surface accuracy.

Orientation

Parallelism

Feature ko datum ke parallel control karta hai.

Hindi: Do surfaces ya axes parallel rehna.

Orientation

Perpendicularity

90-degree relationship control karta hai.

Hindi: Feature ka datum ke saath 90° relation.

Orientation

Angularity

Specified angle other than 90° control karta hai.

Hindi: Drawing par diya hua angle maintain karna.

Location

Position

Hole, pin or feature location control karta hai.

Hindi: Feature ki exact location control karna.

Profile

Profile of Line

2D profile variation control karta hai.

Hindi: Cross-section ki shape control.

Profile

Profile of Surface

3D surface variation control karta hai.

Hindi: Complete surface ki shape control.

Runout

Circular Runout

Rotation ke during individual circular elements variation.

Hindi: Ghumane par ek circular section ka variation.

Runout

Total Runout

Rotation ke during complete surface variation.

Hindi: Ghumane par complete surface ka variation.

4. MMC, LMC and RFS

Modifier Full Form Meaning
Ⓜ MMC Maximum Material Condition Feature contains maximum material.
Ⓛ LMC Least Material Condition Feature contains minimum material.
RFS Regardless of Feature Size Tolerance does not vary with feature size.

Hole Example

Hole size: 10.00 ± 0.10 mm

  • MMC hole size = 9.90 mm (smallest hole)
  • LMC hole size = 10.10 mm (largest hole)

Shaft Example

Shaft size: 10.00 ± 0.10 mm

  • MMC shaft size = 10.10 mm (largest shaft)
  • LMC shaft size = 9.90 mm (smallest shaft)
Hindi: Hole mein material zyada hone ka matlab hole chhota. Shaft mein material zyada hone ka matlab shaft bada. Isliye MMC hole aur MMC shaft ki direction opposite hoti hai.
Note: Bonus tolerance aur virtual condition tabhi calculate karein jab drawing par applicable material condition modifier aur required dimensions clearly specified hon.

5. Practical Inspection Examples

Example 1: Hole Position

A plate has four holes. Drawing specifies position tolerance relative to Datum A, B and C.

⌖ ⌀ 0.10 A B C

Inspection:

  • Establish datum reference frame as drawing specifies.
  • Measure hole axes/centers using suitable equipment.
  • Compare actual position with specified tolerance zone.

Equipment: CMM, suitable functional gauge or other approved method depending on drawing and tolerance.

Hindi: Hole ka center drawing ke specified position tolerance zone ke andar hona chahiye.

Example 2: Flatness

Drawing specifies Flatness 0.05 mm.

▱ 0.05

Meaning: Controlled surface must lie between two parallel planes separated by 0.05 mm.

Inspection: Suitable surface plate, height gauge, dial indicator or CMM method as appropriate.

Hindi: Surface ka total form variation 0.05 mm tolerance ke andar hona chahiye. Flatness ke liye datum reference required nahi hota.

Example 3: Perpendicularity

Drawing specifies perpendicularity 0.05 mm relative to Datum A.

⊥ 0.05 A

Meaning: Controlled feature must remain within the specified perpendicular tolerance zone relative to Datum A.

Inspection: Surface plate, square, dial indicator, CMM or another suitable method.

Hindi: Feature ko Datum A ke reference mein 90° relationship maintain karna hai, specified tolerance ke andar.

6. How to Read GD&T on a Drawing

  1. Identify the controlled feature.
  2. Read the geometric characteristic symbol.
  3. Read tolerance value and tolerance zone.
  4. Check datum references and their sequence.
  5. Check MMC/LMC modifier if present.
  6. Understand the tolerance zone shape and orientation.
  7. Select a suitable inspection method.
  8. Record actual measurement and acceptance result.
Hindi: Drawing mein pehle feature identify karein, phir symbol, tolerance, datum aur modifier read karein. Uske baad inspection method decide karein.

7. Common GD&T Mistakes

  • Datum sequence ko ignore karna.
  • Size tolerance ko geometric tolerance samajhna.
  • MMC/LMC modifier ko incorrectly apply karna.
  • Flatness ko parallelism samajhna.
  • Position tolerance ko simple coordinate tolerance samajhna.
  • Wrong datum setup se inspection karna.
  • Drawing ke standard aur revision ko check na karna.
Hindi: Sirf symbol dekh kar inspection mat karein. Feature, datum setup aur complete drawing requirement ko saath mein read karein.
