Pareto Analysis Formulas

Total Defects = Sum of all defect counts

Defect Percentage = (Individual Defect Count ÷ Total Defects) × 100

Cumulative Percentage = Previous Cumulative % + Current Defect %

Action Priority = Defects contributing to the main cumulative portion of the problem are considered higher priority.

What is Pareto Analysis?

Pareto Analysis

Pareto Analysis is a quality improvement technique used to identify the most important problems from a list of different problems.

It helps a Quality Engineer decide which problems should be addressed first.

80/20 Principle

The Pareto Principle is commonly known as the 80/20 Principle.

In many situations, a relatively small number of causes can contribute to a large percentage of the total problem.

The exact ratio does not always have to be exactly 80/20.

Cumulative Percentage

Cumulative percentage shows the running total of defect contribution after each defect is added in descending order.

Example: 40% + 25% = 65% cumulative.

Action Priority

The biggest defects are normally investigated first because reducing major contributors can have a larger impact on overall quality.

How to Use Pareto Analysis

  1. Collect defect or problem data.
  2. Enter each defect name and its count.
  3. Click Calculate Pareto.
  4. The tool sorts defects from highest count to lowest count.
  5. Check the cumulative percentage.
  6. Focus improvement activity on the major contributors.

Example

Suppose inspection data shows:

  • Burr = 40
  • Dimension Out = 25
  • Scratch = 20
  • Dent = 10
  • Rust = 5

Total defects = 100.

Therefore:

  • Burr = 40%
  • Dimension Out = 25%
  • Scratch = 20%
  • Dent = 10%
  • Rust = 5%

Cumulative percentage becomes:

40% → 65% → 85% → 95% → 100%

This shows that the first three defect types contribute approximately 85% of the total defects. They would therefore be strong candidates for initial improvement action.

Important: Pareto Analysis does not automatically prove the root cause of a problem. It identifies the major contributors that deserve attention. After identifying the major defects, use tools such as 5 Why, Fishbone/Ishikawa, 8D, FMEA or process investigation to find and eliminate the root cause. The 80/20 principle is a practical guideline, not a rule that every process must exactly follow.
