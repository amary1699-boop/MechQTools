How the Calculation Works

The calculator estimates the flat blank length by adding the total bend allowance to the finished straight length.

Bend Allowance = (π / 180) × Bend Angle × (Inside Radius + K × Thickness)

Total Bend Allowance = Bend Allowance × Number of Bends

Blank Length = Finished Length + Total Bend Allowance + Extra Allowance

The finished width is used as the reference blank width. Therefore:

Approximate Blank Size = Blank Length × Finished Width
Important: This is an approximate calculation. For actual production, the drawing, material properties, machine tooling, bend deduction, bend allowance tables and shop trial results should be used.
